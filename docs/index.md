# 筋膜舒緩村

七站，一起學會安心放鬆。點選建築、沿步道漫步，或使用「循序參訪」逐站閱讀。

- 村口服務台：認識筋膜與放鬆原理。
- 工匠鐵匠鋪：球型、平扁、U 型、子彈與氣墊頭圖鑑。
- 運動訓練場：運動前後的溫和使用步驟。
- 守護者哨塔：禁止施打部位與需先諮詢的情況。
- 日常療癒所：久坐族的肩背、腰臀與小腿舒緩。
- 智慧許願池：常見問題與使用迷思。
- 駐村諮詢站：就醫提醒與衛教使用聲明。
